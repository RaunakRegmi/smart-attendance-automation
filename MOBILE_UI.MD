📱 Student Mobile App UI – Attendance + Schedule System (Mobile First Dashboard App)
Design a modern, clean, mobile-first student academic app UI. The app is a dashboard-based system that helps students:

Track attendance percentage
View daily + weekly class schedule (timetable)
Receive smart notifications before classes (including room details)
View attendance insights and risk status
🎨 GLOBAL UI STYLE (VERY IMPORTANT)
The entire UI must follow a dashboard-style card system design:

Visual Rules:
Everything is displayed inside cards (no raw text layouts)
Use rounded modern cards with soft shadows
Maintain consistent spacing system (8px / 16px / 24px)
Clean, minimal, structured layout
Light background with elevated cards
Strong visual hierarchy (important info is larger & higher)
📊 Color System:
Green → Safe / Present / Completed
Yellow → Warning / Partial attendance / Upcoming risk
Red → Critical / Absent / Low attendance
🧱 UI STRUCTURE SYSTEM
All screens must follow this layout pattern:

Primary KPI Section (top summary cards)
Secondary Data Section (graphs / breakdowns)
Action Section (quick actions as cards)
Detailed Data Section (lists / schedules)
Alerts / Notifications Section
📱 BOTTOM NAVIGATION (MOBILE)
Home (Dashboard)
Schedule
Attendance
Insights
Profile
🏠 HOME DASHBOARD SCREEN
This is the main screen.

1. ATTENDANCE SUMMARY (TOP KPI CARD)
A large card showing:

Attendance percentage (circular progress)
Status badge (Safe / Warning / Risk)
Total classes
Attended classes
Missed classes
2. TODAY’S SCHEDULE SECTION (IMPORTANT)
Display today's classes as stacked schedule cards. Each class card must include:

Start Time – End Time
Module Title
Module Code
Lecturer Name
Room Number
Status (Upcoming / Ongoing / Completed)
Behavior:
Highlight current class
Show next class clearly
Dim past classes
3. QUICK ACTIONS (CARD GRID)
Show action cards:

View Full Timetable
View Attendance Details
Weekly Schedule
Notifications Each action is a tappable card.
4. NOTIFICATIONS PREVIEW
Card-based notification list:

Class reminders
Room updates
Attendance alerts
Risk warnings Each notification includes timestamp and category badge.
📅 SCHEDULE SCREEN (TIMETABLE)
Purpose:
Show full weekly academic routing.
Weekly View:
Days of week selector (Mon–Sun)
